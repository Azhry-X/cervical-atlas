How to perform

  2. 2. + Hoffmann's sign.
  3. 3. Inverted supinator sign.
  4. 4. + Babinski sign.
  5. 5. Age > 45 y.

Quebec Task Force clinical classification of Whiplash-Associated Disorders (WAD) from Grade 0 to Grade IV.

Key points

  1. WAD Grade 0: no complaint about the neck; no physical sign(s).
